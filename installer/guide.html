1Installer Copiste

Copiste est proposé sous trois formats. Ils installent tous la même application ; choisissez celui qui vous convient.

.pkgUn assistant d'installation vous guide pas à pas. Le plus simple.
.dmgUne fenêtre s'ouvre : glissez Copiste sur le dossier Applications.
.zipContient l'installeur .pkg et ce guide. Pratique pour l'envoyer par e-mail.

Avec l'installeur .pkg (ou le .zip)

  1. Si vous avez téléchargé le .zip, double-cliquez dessus pour le décompresser, puis ouvrez le dossier obtenu.
  2. Double-cliquez sur Copiste-{{VERSION}}.pkg.
  3. Si macOS indique qu'il ne peut pas vérifier le paquet, suivez l'étape 2, puis revenez ici.
  4. Cliquez sur Continuer, acceptez la licence, puis cliquez sur Installer. Saisissez le mot de passe de votre Mac si on vous le demande.
  5. À la fin, Copiste s'ouvre tout seul. Passez directement à l'étape 3.

Avec l'image disque .dmg

  1. Double-cliquez sur Copiste-{{VERSION}}.dmg. Une fenêtre s'ouvre.
  2. Glissez l'icône Copiste sur le dossier Applications.
  3. Éjectez l'image disque (clic droit sur « Copiste » dans le Finder › Éjecter).
  4. Ouvrez Copiste depuis le dossier Applications (voir l'étape suivante).

2Premier lancement : si macOS bloque l'ouverture

Copiste est un logiciel libre distribué hors de l'App Store, sans la certification payante d'Apple. La première fois, macOS peut donc afficher : « Apple n'a pas pu confirmer que “Copiste” ne contenait pas de logiciel malveillant ». C'est normal, et cela ne se produit qu'une seule fois.

  1. Cliquez sur Terminé (surtout pas sur « Placer dans la corbeille »).
  2. Ouvrez Réglages Système › Confidentialité et sécurité.
  3. Faites défiler jusqu'à la section Sécurité : un message indique que « Copiste » a été bloqué. Cliquez sur Ouvrir quand même.
  4. Confirmez avec Ouvrir quand même, puis saisissez votre mot de passe ou utilisez Touch ID.
💡 La même procédure fonctionne pour l'installeur .pkg s'il est bloqué.

Méthode alternative (Terminal)

Si vous êtes à l'aise avec le Terminal, cette commande retire le marquage « téléchargé depuis Internet » :

xattr -dr com.apple.quarantine /Applications/Copiste.app

3Autoriser Copiste à coller pour vous

Pour coller automatiquement le texte choisi et répondre au ⌥ option + clic droit, Copiste a besoin d'une autorisation de macOS. Elle ne se donne qu'une seule fois.

  1. Au premier lancement, macOS affiche une demande d'autorisation. Cliquez sur Ouvrir les Réglages Système.
    Sinon, allez dans Réglages Système › Confidentialité et sécurité › Contrôle de l'appareil. Sur les versions plus anciennes de macOS, cette section s'appelle « Accessibilité ».
  2. Activez l'interrupteur à côté de Copiste :
    📋 Copiste.app
  3. Vérifiez : dans Copiste, l'onglet Général affiche ✅ « Tout est prêt ».
🔒 Cette autorisation sert uniquement à simuler ⌘V et à détecter le ⌥ + clic droit. Copiste ne se connecte à aucun serveur : tout reste sur votre Mac.

4Utiliser Copiste

Copiste vit dans la barre des menus (icône 📋 en haut à droite) et n'apparaît pas dans le Dock. Il retient automatiquement ce que vous copiez.

  1. Copiez des textes comme d'habitude avec ⌘C.
  2. Cliquez là où vous voulez coller, puis faites ⌥ option + clic droit, ou ⌥⌘V.
  3. Choisissez un élément : il est collé immédiatement.

5Créer vos pré-copies

Les pré-copies sont des textes que vous réutilisez souvent : signature, réponses types, adresse, IBAN, modèles de message… Rangez-les en dossiers et retrouvez-les dans le menu.

  1. Cliquez sur l'icône 📋 de la barre des menus › Gérer les pré-copies…
  2. En bas à gauche, cliquez sur Nouveau dossier, puis renommez-le en cliquant sur son nom en haut de la liste.
  3. Cliquez sur + Nouvelle pré-copie, donnez-lui un titre (affiché dans le menu) et saisissez le texte à coller.
  4. Mettez des mots en gras, en italique ou soulignés avec les boutons B, I, U (ou ⌘B, ⌘I, ⌘U). La mise en forme est conservée au collage dans les apps qui l'acceptent (Mail, Pages, Word, Notes, Gmail…) ; ailleurs, le texte est collé sans mise en forme.
  5. C'est tout : chaque modification est enregistrée automatiquement.
💡 Glissez-déposez les dossiers et les pré-copies pour les réordonner. Un clic droit sur une pré-copie permet de le déplacer vers un autre dossier. Le champ Rechercher filtre par titre et par contenu.

6Réglages utiles

Dans Gérer les pré-copies…, ouvrez la section Général :

  • Lancer Copiste à l'ouverture de session : Copiste démarre tout seul avec votre Mac. Recommandé.
  • Vider l'historique : efface immédiatement les textes mémorisés.

L'historique est gardé en mémoire uniquement : il disparaît quand vous quittez Copiste. Les mots de passe copiés depuis un gestionnaire (1Password, Bitwarden, Trousseau…) sont ignorés. Vos snippets sont enregistrés dans ~/Library/Application Support/Copiste/snippets.json.

7Dépannage

Le menu s'affiche mais rien n'est collé

L'autorisation n'est pas active. Vérifiez l'onglet Général de Copiste. Si Copiste est coché dans les Réglages mais que l'onglet Général affiche toujours ⚠️ :

  1. Dans Confidentialité et sécurité › Contrôle de l'appareil (ou Accessibilité), sélectionnez Copiste et cliquez sur − pour le retirer.
  2. Cliquez sur + et ajoutez de nouveau Applications › Copiste.
  3. Quittez Copiste (icône 📋 › Quitter Copiste), puis rouvrez-le.

Cela arrive surtout après une mise à jour. Le texte choisi reste de toute façon dans le presse-papier : ⌘V fonctionne toujours.

⌥ + clic droit ouvre le menu habituel de l'application

Même cause : l'autorisation n'est pas active (voir ci-dessus). ⌥⌘V fonctionne même sans autorisation, mais le collage automatique en a besoin.

Je ne vois pas l'icône dans la barre des menus

Sur un petit écran, elle peut être masquée par l'encoche ou par d'autres icônes. Fermez quelques icônes, ou utilisez ⌥⌘V puis « Gérer les pré-copies… ». Vous pouvez aussi double-cliquer sur Copiste dans Applications : cela ouvre directement la fenêtre de réglages.

Un raccourci entre en conflit avec une autre application

Dans le Finder, ⌥⌘V sert à « déplacer » un fichier copié, et Copiste prend la priorité. Utilisez plutôt ⌥ + clic droit dans ce cas. Les raccourcis personnalisables sont prévus dans une prochaine version.

8Désinstaller

  1. Quittez Copiste : icône 📋 › Quitter Copiste.
  2. Glissez Applications › Copiste dans la Corbeille.
  3. Facultatif : supprimez vos pré-copies en effaçant le dossier ~/Library/Application Support/Copiste, et retirez Copiste de la liste Contrôle de l'appareil.
